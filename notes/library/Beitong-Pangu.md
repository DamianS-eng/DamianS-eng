# About the Beitong Pangu controller

# How it began

> It all started with a desire to have a modern controller with the Nintendo Wii U Pro Controller layout:
> Both analog sticks raised on the edges, D-pad and buttons on the bottom row close together.
> 
> Then it expanded to "what if the layouts can swap at any time?"
>

# What it is

The Beitong Pangu is a modular modern two-handed controller designed with swappable modules for each of the inputs on the controller. 

This allows both different layouts of input types and overall input types, all usable for both Xbox consoles and PC keyboard and mouse inputs.

# Connection

## USB

> Does not work for Nintendo Switch or Linux PCs

## Wireless

### Dongle

> Does not work for Nintendo Switch or Linux PCs

### Bluetooth

There are three types:

1. Xinput
2. Switch
3. App

> The controller is able to wake the console from sleep; after paired, switch the mode to SW and turn on the controller, and it will immediately try to connect and turn it on.
