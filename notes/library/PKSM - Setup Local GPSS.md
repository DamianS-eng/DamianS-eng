# What is GPSS

The popular save file editor for Pokemon games called [PKSM](https://github.com/FlagBrew/PKSM) has split up its hosted server used for online storage and legality checking measures to a localized instance.

> Legality checks were once possible with an internet connection to PKSM's servers, but they are disbanded in favor of local servers.

# Host it Yourself

1. Locate the latest release of the [Local GPSS repo](https://github.com/FlagBrew/local-gpss/releases/latest).
 - [Windows](#): Run the .exe
 - [Linux](https://github.com/FlagBrew/local-gpss/releases/latest/download/linux64.zip): Mark this file as an executable, and launch from terminal.
